<h1 align="center">Student and Teacher Registration</h1>

### Description

Android app written in Java for registering students and teachers and listing the registered people. It was developed as a partial requirement for the *Projeto Integrador I* course unit of the Internet Computing technical program (*Técnico em Informática para Internet*) at the Instituto Federal do Norte de Minas Gerais (IFNMG).

The app UI is in Brazilian Portuguese. Records are stored on the device with the Android [SharedPreferences](https://developer.android.com/training/data-storage/shared-preferences) API (app-private storage), so they persist after the app is closed. There is no server or network access.

### Features

- Register a student or a teacher with name, address, phone number, ZIP code (CEP), city and state.
- Each record gets a sequential numeric ID per type (students and teachers are numbered separately).
- Clear the form fields with one tap.
- View all registered teachers and students on a single screen.

### Tech stack

- Java (source/target compatibility 1.8), Android SDK: `compileSdk` 34, `minSdk` 30, `targetSdk` 31
- Android Gradle Plugin 8.2.2, Gradle 8.2
- AndroidX AppCompat 1.6.1, Material Components 1.11.0, ConstraintLayout 2.1.4
- Storage: `SharedPreferences`
- Tests (default Android Studio templates only): JUnit 4.13.2, AndroidX Test / Espresso

### Requirements

- [Android Studio](https://developer.android.com/studio) with the Android SDK Platform 34 installed
- A JDK 17 or newer (required by Android Gradle Plugin 8.2)
- An emulator or physical device running Android 11 (API 30) or higher

### How to run

1. Clone the repository and open the project folder in Android Studio.
2. Wait for the Gradle sync to finish.
3. Select an emulator or connected device and run the `app` configuration.

### Project structure

```
app/src/main/java/com/kayo/cadastro/
  MainActivity.java   Home screen: register student, register teacher, view registrations
  Cadastro.java       Registration form (student or teacher, chosen via intent extras)
  Registers.java      Lists all stored registrations
app/src/main/res/     Layouts, strings and themes
.github/              Screenshots used in this README
```

### Tests

The repository only contains the default example tests generated by Android Studio (`ExampleUnitTest` and `ExampleInstrumentedTest`). There are no tests for the app's own behavior.
